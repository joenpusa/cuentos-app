## Librería para parseo de archivos (Excel / CSV)

Para habilitar el soporte completo y robusto para lectura de archivos `.xlsx` y `.csv` en la Carga Masiva, debes instalar la librería `xlsx` (SheetJS).

1. Abre tu terminal.
2. Navega a la raíz del proyecto (`cuentos-app`).
3. Ejecuta el siguiente comando:

```bash
npm install xlsx
```

*Nota: Por ahora, el sistema incluye un lector CSV nativo básico capaz de leer archivos `.csv` delimitados por comas con las columnas `nombre` y `email` en la primera fila.*
